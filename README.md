# Aarvieve Arcade 🎮❤️

A personalized Y8-inspired gaming platform made with love for my girlfriend.

## Monorepo Structure

- `client/` - React, Vite, TypeScript, Tailwind CSS, Phaser.js, Framer Motion, Zustand
- `server/` - Node.js, Express.js, TypeScript
- `shared/` - Shared TypeScript interfaces and types
- `firebase/` - Firestore rules, configuration, and index specifications

## Setup & Running

To get started, follow the instructions in the respective folders.
For the frontend:
```bash
cd client
npm install
npm run dev
```
